How I work

Principles

Math in code, narrative in the model

Numbers get computed deterministically. The LLM explains and contextualizes — it doesn't do arithmetic.

Workflows before agents

I default to fixed, predictable pipelines. I only reach for agent autonomy when a task genuinely needs the model to choose its own steps.

Structured output over prose parsing

When a script needs to use a model's output programmatically, I ask for JSON — not free text I have to regex apart later.

Show the working, not just the result

Every script prints what it's about to send the model, so mistakes are visible before they become a bad report or a bad email.
